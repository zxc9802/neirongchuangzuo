# 餐饮三类型套图

本次改造包含三个方向与一键生成流程。用户选择门店介绍、招牌菜种草、消费场景，填写当前类型的信息，上传1—30张实拍，一键生成。默认成品6张，可调整。

| 类型 | 必填信息 | 必要实拍 |
| --- | --- | --- |
| 门店介绍 | 门店名称、城市或商圈、主营品类 | 门店或用餐空间 |
| 招牌菜种草 | 门店名称、招牌菜名称、真实卖点 | 清晰菜品 |
| 消费场景 | 门店名称、消费场景 | 门店或用餐空间 |

地址、营业时间、价格、口味、外卖、人数、包间、预订分别按类型选填。任务保存当前类型的资料快照和事实，避免隐藏的其他类型信息带入。原有任务继续可查看、下载和重试。

当前素材合成版本为v4。Claude逐批分析实拍，结合所选方向的实际参考图，直接规划每张成品需要的素材区域、主体、摆放、主次、拼接方式和字体。程序先按归一化坐标从原图真正截取区域、组成草稿，Image 2.5整合裁片、食品抠图、环境和文字，一张成品对应一次生图。默认6页至少2页包含多个实拍区域，细节与氛围页可用单个有意义的裁片，避免每页硬拼。不会先把全部原图修饰成摄影资产后套固定拼图，也不固定提亮或用统一系统字体描边。默认输出6张1080×1440 JPEG。

门店介绍和招牌菜参考保留；消费场景使用2026-10-14新提供的4张实拍参考，强调真实聚餐、桌面食物和保留暗部的生活氛围，多数页面允许无字，少量使用小标签。参考图存放在服务端随代码部署，只发送给Claude学习构图和审美，不作为商家原图、不直接用于成品，不把别店的菜品、店名、装修或人物带入。

素材必须引用本任务中已通过检查的原图ID，裁切与摆放区域不能越界。不允许抠出人物组合成虚构聚会。每张记录素材来源、截取区域、构图、风格和参考版本，防止同一套图复用旧方案或误把参考图当原图。字体、字重、字距、色彩、边缘和留白由Claude规划，Image 2.5直接整合排版，不再由程序硬贴粗体文字。标题事实在生图前审核，成品由Claude对照原图、对应参考和编排逐页验收；只重做明确不合格的页面，最多两轮。缺少真实素材不补造菜品、价格、人数、优惠、演出或服务。

不确定的供应商调用结果保留账本并停止该次请求，不自动重发未知调用。已知失败的生图沿用原有三次重试及fal兜底，原图、任务、费用记录和成功的页面检查点保留。旧版任务仍可查看、下载；已有旧版方案不作为新版本任务的复用素材。按现有实际API费用计费。

文件沿用3天保留，任务文字30天保留。结果提供单图、ZIP和配套文案。此次范围不包含可视化版面编辑器、单页重新生图界面或自动发布。
