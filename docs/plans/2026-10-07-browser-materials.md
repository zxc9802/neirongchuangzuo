# AI 混剪网页素材库

用户已确认纯网页方案，接入现有 AI 混剪页面。原视频留在用户电脑；服务器持久化片段描述和向量，在制作时临时接收命中的素材。保留现有页面布局，在素材栏底部显示扫描、向量化和临时上传进度。

1. 复用已验证的浏览器目录扫描、增量索引与分块传输，浏览器存储按登录账号隔离。验证首次分析、返回复用、新增及修改分析、完整扫描删除、权限失效恢复。
2. 复用现有 Python 混剪引擎，作为主站管理的回环服务。Node 主站验证现有账号会话，注入派生账号标识；素材、任务、成片均校验归属。验证匿名、伪造身份、跨账号、跨来源请求被拒绝。
3. 文案驱动向量匹配、按需传片、服务器配音与 FFmpeg 成片，页面显示任务状态和下载。后台分析不阻塞主页面；制作时需保持网页连接。
4. 更新生产 Docker 和启动脚本、配置说明。复用服务器模型及 COS 环境设置，不携带本地密钥、特定业务音色或素材。
5. 运行现有测试与新增契约/浏览器测试；模型、TTS 和云存储可用测试替身，传片与 FFmpeg 使用真实素材。提交独立分支和可审阅 PR。

浏览器限制：桌面 Chrome/Edge 在授权有效时恢复目录并增量扫描；目录输入兼容模式需再次选择。网页关闭或电脑离线后无法读取本机。首版视频单文件最大 512 MiB，临时源文件保留 24 小时。
