# Seedance 2.5 人物复刻实施计划

**Goal:** 在人物 1:1 复刻中增加默认标准版与可切换至臻版，按版本校验和生成最长 15/30 秒视频。

**Architecture:** 复用现有素材、生成、配音、任务持久化与积分链路；服务端模型配置提供显示名称、说明和时长档位，任务保存选定模型。只改变生成请求的 modelId 与对应时长能力。新建默认标准版，提交后锁定版本。

**Tech Stack:** 原生浏览器 JavaScript/CSS、Node.js HTTP 服务、node:test。

**模型依据:** `zxc9802/seedance` 的 `src/modelConfig.js` 明确列出 `doubao-seedance-2-5-260628` 与 `[4,5,6,8,10,12,15,20,25,30]`。共用原 API 地址和密钥。实际扣费沿用当前规则，不推测至臻版的新增费率。
