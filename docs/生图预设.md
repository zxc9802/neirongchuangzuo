# 生图预设的使用与维护

更新：2026-09-30。

两张已制作的工厂样例现已接入生图预设。主流程为上传原图、点选风格、生成；默认文案随风格带入，修改文案为选填，不需要先填写表单或查看完整提示词。目前内置两项，尚未提供后台预设管理界面。

## 在页面中使用

1. 点击「上传产品、门店或车间实拍图」，选完本地图片即带入；已有素材可以通过「从素材库选」复用。
2. 直接点选「工厂宣传海报」或「小红书推销封面」，样式、默认文案、比例和画质立即生效。
3. 点击「立即生成图片」。

需要改字时再点「修改文案（选填）」；完整提示词、比例与画质、商家资料及行业方案均收在「更多设置」。从首页或参考示例使用这两个样式也会直接带入，不再打开文案表单。示例封面不会自动充当用户的原图。

重复点击已选风格不会清空手动改过的创作要求和参数；切换风格会沿用已修改的标题与展示要点。原有完整提示词被替换时，可点「撤销切换」恢复此前的文案与参数，当前原图继续保留。没有使用预设的 Agent 文案或普通草稿会自动展开创作要求，便于直接继续编辑。

选择、编辑和套用预设不会自动发起付费生成请求。只有用户提交生成时，现有图片生成流程才向本网站后端创建任务。

| 预设 | 画面安排 | 默认比例与画质 |
| --- | --- | --- |
| 工厂宣传海报 | 深蓝、金属灰，原图约占 70%，配合精简标题与要点 | 3:4、标准 |
| 小红书推销封面 | 米白底、红黑大字，文字约占 70%，按要点数量安排 1–4 块便签，工艺照片作辅图 | 3:4、精细 |

主标题必填，最多 32 字；副标题与咨询引导可选，各最多 60 字；商家 / 企业名称可选，最多 40 字；每条要点最多 60 字。超出限制会提示修改，不会悄悄截掉文字。留空的选填内容不会补上示例商家或默认联系方式。

如果把默认四条要点改成三条，版式会变成三块便签；标题中的数字属于用户文案，也应一并改为“三点”或其他合适表述。

在「更多设置」中仍可编辑完整提示词。再次进入「修改文案（选填）」并保存时，会按表单重新编译，替换此前手动调整的完整提示词，弹窗会提示这一点。

## 保存和继续修改

点击「保存草稿」后，草稿会保存预设 ID、各字段内容、编译后的提示词及生成参数。刷新后可从「我的草稿」恢复文字与参数，再进入「修改文案（选填）」继续修改。

原图文件不会随草稿保存；刷新后恢复草稿，需要重新选择原图。未点击保存的修改不视为已保存草稿。

## 提示词如何组成

最终提示词由三部分组成：

- 固定的版式、配色、图片与文字比例。
- 用户填写的真实标题、副标题、要点、咨询引导及商家名称。
- 原图保留和真实性约束：保留设备与零件结构；不编造企业身份、价格、产能、认证、客户、精度、交期或承接承诺。

小红书的信息块数量根据实际非空要点行数生成。预设编译器会处理 CRLF 换行并忽略空行；不以示例中的固定四条替代用户内容。当前允许的最大字段组合编译后，工厂海报为 795 字，小红书封面为 829 字，均在现有生图接口的 1000 字限制内。

## 代码位置

- `design/image-presets.js`：预设元数据、默认文案、字段限制、校验和提示词编译器。此模块不访问页面、网络或浏览器存储。
- `design/image-preset-ui.js`：直接选择风格、可选文案表单、撤销切换与校验提示。
- `design/material-catalog.js`：两张参考图分别通过 `presetId` 关联 `factory-poster` 和 `xiaohongshu-cover`。点击相关参考图的使用入口，会直接选用该风格并保留已有原图。
- `design/image-generation.js`：沿用现有上传校验、任务提交、状态查询和结果展示流程。
- `tests/image-presets.test.mjs`：预设编译与校验测试。
- `tests/image-preset-ui.test.mjs`：直接选择、同样式保留手改、跨样式文案复用、首页原图及撤销回归测试。

以下示例说明参数如何变成同站后端的生图请求。`uploadedImages` 表示现有上传流程处理好的原图数据；此示例不是需要另接一套生成接口的实现，也不应在套用预设时执行请求。

```js
import { getImagePreset, getPresetDefaults, buildPresetPrompt } from './image-presets.js';

const id = 'xiaohongshu-cover';
const preset = getImagePreset(id);
const fields = {
  ...getPresetDefaults(id),
  title: '加工询价，这三点先说清',
  subtitle: '需求写清楚，沟通更直接',
  points: '材料要求｜说明材质和用途\n加工数量｜说明样件或批量\n关键尺寸｜标注装配和检测要求',
};
const prompt = buildPresetPrompt(id, fields);

// 仅说明用户提交生成时的请求形状；实际页面沿用现有任务流程。
function submitAfterUserClicksGenerate(uploadedImages, requestId) {
  return fetch('/api/ai/images', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      requestId, prompt, images: uploadedImages,
      ratio: preset.ratio, quality: preset.quality,
    }),
  });
}
```

模型密钥继续只保存在服务器配置中。前端调用本站 `/api/ai/images`，不直接携带密钥请求模型平台。

## 后续增加预设

新增预设需要在 `IMAGE_PRESETS` 中添加唯一 ID、名称、说明、封面、比例、画质和五个默认文案字段，并在界面中检查效果。若有对应参考图，再为素材添加相同的 `presetId`。

**当前编译器按 ID 区分两种样式，且布局文字固定写明 3:4。** 因此不能只新增一张卡片：应同时扩展 `buildPresetPrompt` 的对应布局分支；采用其他比例时，须同步调整生成参数和提示词中的比例描述。否则新增 ID 会沿用小红书布局，出现卡片说明和实际创作要求不一致的问题。

新增餐饮、美业、零售或其他工厂行业预设时，默认文案应是可替换的表达示例，不能预设某家企业的价格、资质或经营承诺。应补充字段替换、布局差异、必填校验、最大长度和默认值隔离测试。
