# 资产库整理功能（2026-10-24）

- 上传素材和生成作品支持前移、后移及同一区域内拖动排序。
- 排序按账号保存，刷新后保留。
- 支持单项、批量删除，以及在“已删除”中恢复。
- 删除隐藏资产库记录，不移除任务引用的原始文件。
- 上传素材继续长期保留；生成作品沿用原有三天有效期，恢复不会延长有效期。
- 新增操作适配亮暗主题及中文、英语、马来语。
