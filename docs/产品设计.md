# 门店宣传 AI 平台 · 产品与交互设计 v0.4

## 1. 本轮方向

用户指定以 https://maolong.da-ai.cc/ 为主要交互和视觉参照，面向实体门店老板，包含 AI 图片、AI 视频、AI 混剪、数字人智能体四大模块。原 Oumomo 版本已经停止运行并移到回收站。新仓库属于 inmyeyes4577，当前保持远程空仓库。

当前包含**可点击工作台、产品规格和数字人后端接入**。首页增加场景摄影与发现内容，图片和视频保留参考站三栏结构，混剪有独立工作区。数字人采用同事项目的生成后端；本次按用户要求参考 Oumomo 调整为上方生成、下方懒加载素材与作品，保留现有蓝白工作台风格。

数字人页面已按真实接口接入形象视频、参考声音与任务管理；上传素材由数字人后端持久化保存。模型凭据和公共媒体访问条件尚未配置齐备，生成按钮显示待配置原因并禁用，尚未完成真实出片验收。其余模块仍为原型：选入素材只在当前页面内存中使用，刷新需重新选择；文案、参数、门店资料和收藏保存在当前浏览器的 localStorage，不包含素材文件本体。

## 3. 定位与信息结构

暂用名称「门店 AI」，正式名称待定。面向餐饮、美业、健身、零售、家政、家居等实体服务商家；行业暂不锁死。

顶级导航：**首页 / Agent 对话 / AI 图片 / AI 视频 / AI 混剪 / 数字人 / 资产**。Agent 对话位于首页和 AI 图片之间，作为独立辅助入口；四个创作模块仍可直接使用。门店档案是共有资料入口。用户明确排除画布：不做画布页面、无限画布、节点连线、节点式工作流编辑器，也不保留占位入口。混剪时间轴用于视频编辑，保留。

首页场景：活动海报、门店宣传、招牌项目、同城团购、老板口播、日常混剪。老板先选宣传目标，系统带入对应模块和模板。

成功指标：老板能用自己的真实素材，在尽量少的输入下产出可预览、可修改、可下载的宣传内容；店名、地址、活动日期与价格正确；能复用上次的门店资料和风格。

## 4. 页面布局与视觉

视觉主张：沿用参考站明亮灰白、窄导航、轻边框、大编辑面板的工作台体验，以蓝色标识当前动作；避免重新做成上一版的深绿工具集合。

页面结构各有侧重：

- 首页：大输入框、快捷工具、摄影场景入口、发现与收藏内容流；可以查看参考、按行业筛选并带入创作要求。
- 图片、视频：左侧素材与文案、中间原始素材或摄影参考、右侧草稿记录，参数和提交操作在编辑区底部。
- 混剪：左侧实拍素材池、中间原视频播放器、右侧剪辑设置、底部横向素材序列。
- 数字人：上方集中选择视频形象、参考声音并填写口播文案，生成参数折叠收纳；下方以卡片网格展示素材和作品，滚动时逐页加载，点击卡片查看或复用。

交互保持轻量：导航与弹窗进入、摄影卡片悬停、素材选中反馈；尊重减少动态效果设置。删除画布入口，不以不能工作的图标填充页面。

桌面保留约 74px 窄侧栏，移除顶部“设计稿”横条，把空间留给工作区。图片与视频预览自适应，混剪按素材、预览、参数分栏；数字人页面纵向滚动，生成区和展示区共用页面宽度。窄屏表单纵向排列、卡片减少列数，混剪素材条可横向滚动。

本轮已实现的细节：技能分类与搜索、输入字数、素材数量与移除、参数摘要、统一素材选择、草稿保存恢复、图片视频文案展开和任务队列折叠。数字人已对接服务端任务进度、历史、结果预览与下载接口，真实成片效果待模型联调；其他模块的生成结果、继续修改、下载及送入混剪仍为后续设计。

## 5. AI 图片

目标：做活动宣传图、团购套餐图、招牌项目展示、门店氛围图、朋友圈九宫格。

| 技能 | 最少输入 | 可选补充 | 输出设计 |
|---|---|---|---|
| 活动海报 | 门店/服务原图 + 活动内容 | 时间、价格、主题 | 海报及不同比例版本 |
| 团购套餐图 | 套餐或服务照片 + 套餐说明 | 划线价、到店限制 | 团购展示图 |
| 招牌项目 | 项目/菜品/产品照片 | 核心特色 | 主视觉与局部展示 |
| 门店氛围 | 真实门店照片 | 色调、时段 | 保留店面结构的氛围图 |
| 朋友圈九宫格 | 多张门店素材 | 统一标题、活动主题 | 同风格九张图 |
| 图片精修 | 一张原图 | 指定保留和修改内容 | 清晰、曝光和细节修正图 |

操作链：选技能 → 上传/选门店素材 → 一句补充（有要求才填写）→ 自动推荐尺寸 → 生成 → 预览/修改/下载。

活动的店名、金额、地址、日期应作为可编辑文字图层保存，避免完全依赖模型把字画对。商业宣传默认保留真实门店招牌和空间结构，明确区分真实展示与创意效果图。链接输入后续可用于导入用户可访问的门店资料，不能承诺任意平台链接都能抓取。

## 6. AI 视频

目标：把图片、门店信息与宣传意图变成新的宣传视频。与混剪共用素材，但生成逻辑不同。

场景：门店发现、到店实录、招牌体验、同城团购、开业预热、节日活动。

默认路径：选场景 → 添加参考图片和门店 → 填一句宣传目标 → 生成脚本 → 确认文案与分镜 → 生成视频 → 下载或进入剪辑。

保留「直接生成 / 宣传编导」切换。直接生成适用于明确提示词；编导模式给出开场、店内环境、核心项目、价格/活动、到店引导五类镜头，可逐镜修改。对无需修改的用户，给一个明确的整片生成按钮。

默认竖屏，支持横屏。长度、配音、字幕、音乐、封面和门店片尾模板组成视频配置。生成费用在发起前按配置估算；多个分镜失败时可单独重试，已成功片段可复用。

## 7. AI 混剪

目标：把老板已拍摄的门店视频自动整理成片。已有实拍素材是主体，不要求先用 AI 重造每个镜头。

默认路径：批量上传片段 → 选宣传目标 → 自动分析与选片 → 文案/字幕/配音/音乐匹配 → 生成编排预览 → 必要时在时间轴微调 → 导出。

当前独立编辑器已实现：左侧选择本地视频；中间用原生播放器真实播放所选视频；右侧设置宣传主题、要求、目标时长、成片数量、字幕、音乐与输出规格；底部选择片段并前移、后移或移除。素材时长来自所选文件，不展示虚构生成进度。

后续完整编辑器再增加门头/环境/服务等用途分类、入出点、片段音量、字幕样式、切割、磁吸、缩放与片尾。当前底部是素材顺序编排，尚未生成可精确剪裁的成片时间轴。

批量成片是明确设置：同一素材库可以生成不同开场、顺序、文案的多个版本，显示具体数量与费用，不能把重复导出同一视频描述为不同作品。避免同一条成片内重复使用同一片段。

真实媒体处理阶段需要实现：调整入出点、原声控制、字幕、音乐合成与导出。高级转场、关键帧、多机位和复杂特效再后置。

## 8. 数字人智能体

目标：帮助老板用自己的口播视频和参考声音持续制作宣传内容。本轮直接采用同事仓库 `zxc9802/shuzirenzhinengti` 的生成后端，在本站重新实现符合现有风格的前端。

实际流程：**选择或上传人物口播视频 → 选择或上传参考声音 → 填写宣传文案 → 设置生成参数 → 提交任务 → 查看真实进度 → 预览并下载成片**。形象素材是视频，图片仅作为封面，不支持把一张照片直接变成口播视频。

页面采用上下布局，使用本站的导航、字体、蓝色按钮和浅色面板。上方生成区集中放置视频形象选择、声音选择、口播文案及生成按钮；语气、情绪强度、视频适配和生成引擎放入可展开的参数区。音色仍支持上传、管理与试听。没有接入的背景替换、字幕排版、包装效果不显示为可用设置。

下方“我的创作”通过“全部 / 视频形象 / 生成作品”切换卡片网格，默认每页 12 条。接近列表底部时请求下一页，同时保留手动加载、失败重试与加载完毕提示。图片按需加载，卡片不批量下载完整视频；预览在用户打开后播放。形象可选择用于上方生成，作品保留真实状态、预览、复用与下载操作。

展示区使用新增 `/api/digital-human/library`，按创建时间倒序及稳定键分页；切换分类重新读取第一页，不混入旧分类的请求结果。接口同时返回当前已选素材和进行中的任务，避免尚未翻到所在页时丢失选择或进度。服务端沿用原有素材及任务的访问权限和公开数据结构。

形象与参考声音由后端保存，刷新后可再次加载并用于后续任务。音色没有有效参考音频时不能当成可用默认音色。任务列表和进度使用服务端数据，支持历史记录、成片下载及服务端标记为可恢复任务的恢复操作；恢复已有结果不等于自动重新提交任意失败任务。

页面通过 `/api/digital-human/status` 判断配置是否齐备。缺少模型凭据、对口型引擎或外部模型可访问的媒体条件时，显示原因并禁用生成；上传和素材管理仍可在本地服务可用时使用。状态返回就绪只代表配置齐备，不代表供应商账号、额度和生成效果已经实测可用。

前端入口为 `http://127.0.0.1:5173/#avatar`，页面文件为 `design/digital-human.js`、`design/digital-human.css`，接口适配为 `design/digital-human-api.js`。`preview.mjs` 将同源接口和媒体请求流式转发至 3001 的数字人服务；原生制作台保留用于联调。`npm run dev` 一键启动工作台和后端，或复用已有数字人服务。

可继续围绕老板介绍、招牌讲解、活动通知、到店路线与常见问题提供固定文案模板，但不能把固定文案说成模型生成。门店信息辅助写稿、自动改稿、字幕、背景和加入门店镜头属于后续能力，需分别实现与验收。价格、日期等事实由用户确认，不自动编造。

后端已有配音、FFmpeg 处理和对口型适配，但本地尚未完成真实模型出片；正式上线仍需配置自己的模型与媒体服务以及正式账号方案。接口、运行条件和验收记录见 [数字人前端对接](数字人前端对接.md)。

## 9. 门店资料与资产

门店字段：名称、行业、地址、营业时间、联系方式、特色、服务/套餐、活动有效期、Logo、品牌色。首次可跳过资料建档，在实际生成需要时逐步补齐。门店档案始终可编辑；历史任务保存当时资料快照。

AI 图片、AI 视频、AI 混剪与 Agent 对话使用页面内素材池，选入一次可在本页复用；选择器支持图片/视频/声音类型筛选与文件名搜索。各入口限制可选类型，视频创作添加声音时保留已有图片。此原型素材池刷新后不会保留文件。

数字人使用独立后端的形象库和音色库，上传的视频与参考声音持久化保存，刷新后可重新加载。它们尚未并入全站统一素材库，不能把原型素材池中的文件当成已上传到数字人后端。

后续素材库设计：门头、环境、产品/菜品、服务过程、老板、配音、音乐、生成结果等标签，以及门店归属与来源筛选。

不能自动把所有客户记录或私密资料送给模型；任务仅引用被选中的素材与必要门店字段。

## 10. 状态与异常设计

通用任务的后续设计：草稿 → 待提交 → 排队 → 处理中 → 待确认脚本（可选）→ 成功 / 部分成功 / 失败 / 已取消。当前数字人沿用后端的 `pending`、`processing`、`completed`、`failed` 状态，以及配音、视频处理、对口型和导出等实际执行阶段；没有实现的取消和部分成功不伪造显示。

素材上传显示进度、数量和失败原因。切换模块保留草稿。生成时显示真实阶段与已耗时，百分比必须来自实际服务。其他原型模块在提交时说明服务待接入；数字人提前显示后端连接及配置状态，生成条件不齐备时禁用提交。不展示虚假的生成结果或积分消耗。

额度不足、文件超限、格式不支持、服务不可用、单片失败都提供对应处理入口。重试复用已有素材和成功片段；对状态不确定的请求先查原任务再重提。取消后说明是否已经提交外部服务。

## 11. 实现顺序与验收

阶段 1：核对布局与交互设计。已补齐首页摄影内容、发现收藏、图片视频三栏工作区，以及独立混剪和数字人页面。首页、Agent 对话、图片、视频和混剪的生成能力仍处于原型阶段。

阶段 2：页面与后端基础版。当前优先接入数字人，复用同事项目的素材与任务接口，并完成本站前端、同源代理和本地启动。全站登录、门店、统一素材库、持久化队列与回调仍需后续开发；数字人生产账号可采用上游独立账号模式并配置 PostgreSQL，不能将本机免登录开发身份用于上线。

阶段 3：真实生成联调。至少各完成一条实际图片、视频、实拍混剪和数字人口播，并可下载；验证失败重试和费用归属。

阶段 4：精细对齐。根据参考站真实结果页补齐再创作、生成作品收藏、分镜确认和任务细节；首页参考内容收藏已在原型中实现。收费、订阅、团队协作单独验收。

验收重点：四模块不会互相丢草稿；素材可复用；关键事实不会被悄悄改写；失败后可恢复；原始素材与输出可区分；原站未核实之处不标成已经复刻。

## 12. 当前实现边界

`design/` 是原生 JavaScript 工作台；其中数字人已按后端接口实现素材管理和任务操作，其余创作模块仍为静态原型。首页摄影是风格参考，不冒充用户作品或生成结果；混剪播放器可以播放用户选入的视频，排序只改变素材序列，尚未实际合成或导出。固定模板文案不是模型生成结果。

原型模块的素材仅在页面内存中保存，刷新需重新选择；草稿、门店资料和收藏使用 localStorage。数字人的形象视频和参考声音会真实上传到后端，按服务配置保存到本地持久目录或对象存储，任务状态与结果以服务端为准。全站统一素材库尚未接通。

数字人后端保留真实配音、对口型、视频处理、结果下载和账号接口；本站页面已适配这些接口，未配置齐备时禁用生成。当前没有真实模型出片、PostgreSQL 账号或生产部署的验收结果。仅本机未配置 SSO 的开发模式可免登录，正式账号仍需配置并验收。`/api/digital-human/status` 不返回密钥，其配置就绪状态不能替代一次完整出片测试。

其他模块尚未实现真实模型调用和导出；全站积分支付、统一账号与云端门店素材管理也未完成。不展示假积分、假进度或假成片。新 GitHub 远程仓库尚未上传本轮文件。

## 13. 本轮验收重点

桌面视觉验收使用外置 Chrome 调试浏览器的实际窗口，主基准为 1920px 宽；不用 Codex 内置浏览器被侧栏挤压的视口作为桌面布局基准。首页取消遗留的 1500px 页面限宽，参考内容按卡片自然高度填充瀑布流，并在筛选和容器宽度改变时重新排布。

- 首页灵感可以筛选、收藏、查看并带入对应模块；摄影参考不显示为生成成品。
- 图片和视频的文案、参数与草稿可保存恢复；模块切换不会覆盖其他模块草稿。
- 素材搜索、类型限制和多选一致；新增声音不清空已经选择的图片。
- 混剪可以选择并播放本地视频，前后移动和删除片段后预览与顺序一致。
- 数字人上传视频形象和参考声音后，刷新仍可加载并预览；没有参考音频的默认音色不当成可用素材。
- 数字人上方生成、下方展示；展示区分页不重复，切换分类不混入旧数据，并提供加载失败重试及列表结束提示。
- 数字人使用真实参数和任务状态；接口或公共媒体条件不齐备时禁用生成；历史、下载和恢复操作遵循后端返回结果。
- 页面在桌面和窄屏均可操作；原型模块在提交时说明服务待接入，数字人状态提示不遮挡素材管理与文案编辑。

混剪时间轴为素材排列原型，未声称实现精确裁剪或实际渲染。数字人页面与接口联调结果见[数字人接入验收](数字人接入验收.md)；真实成片效果、供应商调用与生产部署仍需配置完成后验证。
