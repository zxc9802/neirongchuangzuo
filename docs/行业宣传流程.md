# 实体生意宣传流程

2026-09-28 实现。适用主营用户为实体门店、工厂、生产加工和批发企业；内容结构来自本次小红书、抖音样本调研。样本的互动数据和经营事实未作为本站商家的事实预填。

## 用户操作

1. 首页选择行业、宣传用途、发布平台与制作类型，补充想法最多 400 字，也可先选真实素材。
2. 打开信息表单。已有商家名称、地区和特色自动带入；行业、用途和活动类型决定字段。
3. 填写需要的真实事实。缺少必要信息时定位具体字段，金额错误时给出原因。
4. 整理方案，检查发布文案、可朗读口播稿、组图或镜头顺序、风格与素材清单。可返回修改或下载文字方案。
5. 点击用于图片、视频、混剪或数字人。此时才替换目标创作要求及素材选择。方案内的文字仍可在工作台继续编辑，原方案作为参考快照保留。

图片、视频工作台在有方案时默认展示“宣传方案”。数字人仍采用上方制作、下方按需加载素材与作品的布局，接收口播稿，不把镜头指令放进口播文本。

## 素材展示与方向复用

首页与图片、视频工作台共用 `design/material-catalog.js` 中的 30 个素材方向。新生成的 12 张行业图片优先展示，覆盖门店、家具、服装代工、工业加工及批发业务；既有摄影参考和形象参考继续保留。首页先展示 12 项，每次加载更多 6 项，行业筛选与收藏基于同一份展示库。

六类宣传场景分别使用独立生成的封面，不重复使用素材列表中的图片。新增共 18 张图片均为内置 `image_gen` 生成，包括 12 张行业素材及 6 张场景封面。摄影素材标为“摄影参考”，新生成图片标为“AI 风格示例”，既有老板形象标为“AI 形象参考”；这些画面均不代表用户自己的产品、厂房、产能或服务效果。

查看素材详情后，点击“用我的素材创作”带入行业、用途和创作要求，再上传或选择自己的真实素材。此操作不会把参考图片添加为用户素材，也不把 AI 图片中的产品、工序、库存或经营条件作为商家事实。摄影来源及生成提示词见 [素材来源](../design/media/SOURCES.md)。

## 行业与用途

| 行业 | 重点信息 |
| --- | --- |
| 餐饮、咖啡茶饮 | 招牌、真实环境、到访安排、活动权益 |
| 美业、生活美容 | 实际成品、服务过程、适用条件、预约方式 |
| 零售 | 品类、规格、选择建议、活动条件 |
| 运动健身 | 场地、课程、体验与到访安排 |
| 工厂直销 | 材质、零售或定制、交付与安装 |
| 生产代工 | 承接范围、起订、打样、交期确认 |
| 工业加工 | 材料、工艺、规格、询价资料 |
| 批发供货 | 起批、混批补货、库存与发货 |

六类用途：门店实景、服务案例、活动促销、选购攻略、工厂询价、品牌展示。每个行业只显示适用用途。小红书侧重主题封面与可回看的条件说明；抖音侧重开头、证据与行动；朋友圈优先展示业务和权益。平台模板不保证曝光或获客效果。

活动区分套餐、代金券与单品：代金券单列支付金额、抵扣金额、门槛、有效期与限制，不能暗示包含展示画面中的所有商品。图片和视频指令要求保留真实产品、场地、材质和效果，未填写的价格、产能、销量、认证与评价不补造。

## 状态与保存

- 公共商家资料、最近填写的信息、方案草稿保存在当前浏览器；没有上传新的商家数据库。
- 同一商家更新地址、特色或接待时间时保留本次活动信息；名称或行业改变时清空最近填写的活动和采购信息，保留平台偏好。已有创作与已保存草稿仍保持原始快照。
- 信息表单中的素材选择暂存，确认使用后才提交；取消不会覆盖原作品的文案、方案或文件选择。新上传素材仍可在当前页面素材池找到。
- 图像可在图片与视频制作间复用，类型不兼容的素材不会带入。超出数量上限需要移除多余素材后继续。
- 图片、视频、混剪的文件仍是本页预览，刷新后重新选择。数字人已上传的视频形象和参考声音由原后端管理。

## 实现与边界

- `design/business-catalog.js`：行业、用途、平台、动态字段、校验与确定性文案模板。
- `design/business-flow.js` / `.css`：共享填写、审核、素材暂存、下载和转入流程。
- `design/home.js`：行业入口、六类独立场景封面、分批展示与方向复用。
- `design/material-catalog.js`：首页和工作台共享的 30 个素材方向、行业信息及来源标注。
- `design/app.js`：公共资料、模块上下文、草稿快照。

图片、视频与混剪尚未接入模型生成服务，当前可真实完成信息整理、方案下载及草稿流转。数字人保持现有真实后端接口；模型密钥、音色与公共媒体配置完成并实测后才能生成成片。此次未部署、未推送远程仓库，未新增画布。
