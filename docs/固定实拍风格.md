# 固定实拍风格

已固定 8 张酒馆照片及 1 张江景照片的编排、实际生图提示词和已确认成品参考。入口为「AI 图片 → 餐饮小红书 → 一键生成套图」，默认张数跟随上传数量。支持分别上传酒馆 8 张、江景 1 张，也支持合并上传 9 张。

服务端根据实际照片内容识别，不依赖文件名或上传顺序。仅容忍上传压缩产生的微小差异；换图、明显裁剪、重复照片或混入新照片不会套用这套已确认方案。

每次创建新任务仍调用当前生图模型，提交原图、固定提示词和对应的已确认成品作为风格参考。Claude 将新成品与已确认风格比较，允许细节变化；明显换色调、氛围或主要主体时最多调整两次。人物近景沿用已确认的常规曝光与色彩参数，不重新生成脸。恢复同一任务会复用已通过检查的图片，避免重复调用和扣分。

方案位于 `services/restaurant/style-recipes/manifest.json`，图片参考随 `services` 打入 Docker 镜像，不属于三天清理目录。用户任务图片和下载包仍按原规则保存三天。调整方案需要更新版本号，旧版本未完成任务需要重新上传；不要直接替换参考文件而沿用旧版本号。

这里固定的是这组已确认素材的摄影方案，并未将酒馆或江景色调强行应用于其他商家素材。其他照片继续走独立分析与编排流程。
