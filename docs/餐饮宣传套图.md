# 餐饮宣传套图

新任务默认“宣传套图”：基于商家实拍提取食品视觉身份，再进行更有食欲的AI商业重拍。允许改善食品摄影质感、变化镜头和设计餐馆场景，尽量保持食品组成、明显数量、相对分量、原有配菜、餐具和摆盘关系。

自然美化、封面加字继续使用常规处理。上传、选方向、设置张数、生成的页面流程不增加步骤；现有原图数量及成品数量限制不变。

## 生成链路

1. 照片分析为菜品输出 `foodAppearance`：形态、相对分量、摆盘、餐具、主要颜色、可见组成、纹理、辨识特征、未确认细节、可辨数量。不明确的数量为 `null`，不猜菜名、配料、工艺或内部断面。旧任务缺少档案时，在生成选中的菜品前补充识别，并保存到任务分析中。
2. 按菜品选择设计餐馆类型：牛排→高端西餐厅，肠粉/粥粉面/早餐小吃→街坊小馆，其他支持休闲西餐、火锅、烧烤、海鲜、甜品、中式家常餐馆。依次规划斜俯拍主视觉、90度俯拍摆盘、食欲近景、用餐氛围镜头。
3. 调用现有图片模型的 `/images/edits`，每张明确提供自己的原图、视觉档案、目标机位、对应餐馆、照明及食品摄影要求。同类餐馆保持材质和摄影风格，背景位置与角度可以变化。不传另一张成品作为视觉参考，减少对其机位和背景的照抄。
4. 成品与原图一起交给视觉模型，检查 `identityMatch`、`sceneMatch`、`shotMatch`、`compositionUsable`：是否改变食品、增减明显食物、改变餐具、出现错误餐馆、忽略目标机位、悬浮、断盘、塑料质感或主体截断。合理视角、曝光、色彩和润泽变化不视为身份变化。
5. 已完成但有明确偏差的成品，允许一次修正重拍；始终重新带原图，不把错误成品当成事实。两次不通过则整套失败、积分释放。上游结果不确定、额度不足或结构化审查失败不会进入付费自动重拍。
6. 通过检查后输出1080×1440，以预留区域加短句和店名。环境、门头、制作和人物照片保留完整实拍并轻度美化、排版，不重绘门店或人物。
7. 文案和发布审查始终看实拍资料；生成餐馆背景不是实际装修、价格、食材、口味或设施的证据。

## 正文质量

正文采用老板个人账号口吻：从所选顾客的用餐念头切入，用一两处可靠细节展开这一餐的吸引力，最后给一次自然邀约。不同品类沿用各自的消费场景，不统一套聚餐模板，也不把照片坐标、盘碗位置或识别清单写成宣传内容。

常规正文建议250—500字符；只有确认品类与少量外观事实时，可自动写150—240字符简版，不强行凑到250字，不增加商家操作或长度确认。真实性、重复、报告用词与风险检查保持生效。

写作输入只提供原图、可见对象、场景、风险、门店资料、确认事实和方向的顾客/场景；摄影视觉档案、坐标和推荐报告保留给原有分析与审查，不送入写作。能直接辨认的肉片、绿叶菜、菌菇、红汤可用通用日常名称并追踪原图，不推断肉种、菜名、配方、口味或真实装修设施。

本地检查拦截“薄片状食材”等报告用词，以及主要在解说画面的正文；已完成的弱文案最多自动改写一次，随后继续事实审核。沿用失败释放积分和未知请求不重放规则，自动改写不额外扣商家积分。

## 状态、账本与积分

食品阶段为 `food_identity`、`food_render`、`food_consistency`，随后沿用文案、发布包、确认和完成流程，不增加“部分成功”。

付费图像请求与通用生图共享每日调用预算。每个任务、原图、修正序号对应独立且确定的调用标识；已发送请求不能再次发送。通过检查的结果在任务内存缓存，本地排版重试不重复调用；重启恢复沿用任务失败处理，不重放已发送请求。

积分按成功交付的图片50分/张结算。识别、审查、自动修正不额外扣商家积分，但占实际模型调用预算。整套失败释放预留积分；同一完成任务重复提交不再扣积分。

图片与ZIP保留三天，文字记录保留三十天。视觉档案保存于任务分析；成品元数据保存源图ID、源图哈希、场景、镜头、调用标识及一致性检查结果。

## 配置与兼容

沿用既有图片/对话接口配置，不新增服务或密钥。商业重拍不依赖本地抠图模型，Docker构建不再自动下载U²-Net权重；保留旧分割工具供兼容或单独调试。

`imageMode` 支持 `promotional`、`natural`、`cover`；网页显式提交 `promotional`，省略字段的旧调用仍按 `natural`。文案可选 `imageCaptions:[{imageId,text}]` 覆盖最终图片，短句8—16个汉字、最多24字符，受同样的事实审核。

## 校验

`npm run check`、`npm run test:restaurant` 覆盖视觉档案、场景匹配、镜头计划、原图请求、共同预算、调用幂等、质量偏差修正、未知请求禁止重放、事实审查、发布包及积分。

一致性检查过滤明显偏差，真实食物细节与食欲效果仍需查看；生成图片不承诺与原图逐像素相同。
