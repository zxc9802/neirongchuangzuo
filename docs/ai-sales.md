# AI带货模块

- 入口：`/#ai-sales`。仅通过会话认证的 `义鹏` 与 `admin` 账号开放；昵称、手机号与客户端权限标记不作为授权依据。
- 默认：30秒、480p、9:16、带音频。复用视频素材、编导、计费和生成链路，采用独立的 `ai-sales` 创作方向与任务列表。
- 编导：上传角色照片、声音、产品/场景素材；支持固定文案。人物必须在开场、中段展示、结尾被引用并有动作；固定文案按全文校验，不通过时进入结构化修正。
- 默认人物与声音：部署到运行时 `video-creator/sales-preset/character.jpg` 与 `voice.wav`。只能由授权账号读取，不放入Git或公开静态资源目录。未配置时允许用户自行上传。
- 草稿文字与当前会话ID按账号保存在浏览器；已提交脚本和任务在服务端保存，可从本模块历史打开。视频、上传文件沿用现有3天保留策略；默认人物与声音独立保留。
- 指定文案、人物引用校验属于生成前检查，不能替代成片的人脸、动作、口型、发音和事实效果验收。
- 验证：`node --test tests/ai-sales.test.mjs tests/video-creator*.test.mjs tests/workspace-auth.test.mjs`。
