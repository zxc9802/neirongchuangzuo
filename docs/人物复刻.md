# AI 视频 · 人物 1:1 复刻

输入一段单个人物的视频，再输入一张目标人物照片，由视频模型替换人物。页面可切换「qiya-2.0 / qiya-2.5 / qiya-2.0-f1 / qiya-20-m1 / PixVerse Swap / Wan 2.2 人物替换」，供应商模型 ID 保留在请求协议和技术文档中。qiya 固定提示词明确人物外貌、发型和服装均采用照片，去掉原人物与照片不一致的服饰、配饰和衣服文字，替换贯穿全片。保留原视频的动作、表情、说话节奏和镜头运动，以及人物以外的场景、商品、背景标识和已有字幕；不新增动作、重复片段或延伸表演。这些是生成目标，不是逐帧一致保证。

四个 qiya 版本共用上述替换指令。IndexTTS2 独立配音模式下，画面生成请求不再叠加逐句台词、时间线和补时表演要求；原始台词与时间线仍保存在任务中，供后续配音与口型流程使用。直接生成声音的路线继续附带台词与时间线要求。

## 使用

1. 打开「AI 视频 → 人物 1:1 复刻」，选择参考视频和目标人物照片，可额外添加声音参考。账号的页面模式会记住，刷新后继续显示人物复刻。
2. 点击「上传素材，查看费用」。服务端检查视频时长与照片格式，显示生成时长和积分预估。
3. 点击「开始人物复刻」。素材审核、生成、保存与结算状态会自动更新；可离开页面，再从最近记录查看。
4. 成片可播放和下载，也会出现在「资产 → 视频」。成片保留 3 天。

刷新页面后默认显示空白的新建复刻表单，配音默认使用 IndexTTS2；点击「最近的复刻」中的记录才打开对应素材、生成进度或成片。刷新不取消后台生成任务。

### 生成版本

- **qiya-2.0**（默认）：Seedance 2.0，模型 ID `doubao-seedance-2-0-260128`，最多 15 秒，1 元/秒（125 积分/秒）。
- **qiya-2.5**：Seedance 2.5，模型 ID `doubao-seedance-2-5-260628`，最多 30 秒，1.5 元/秒（187.5 积分/秒）。
- **qiya-2.0-f1**：Seedance 2.0 fast，模型 ID `doubao-seedance-2-0-fast-260128`，最多 15 秒，0.8 元/秒（100 积分/秒）。
- **qiya-20-m1**：Seedance 2.0 mini，模型 ID `doubao-seedance-2-0-mini-260615`，最多 15 秒，0.5 元/秒（62.5 积分/秒）。显示名称按价格表原文保留。

四版沿用同一 API 地址、项目和密钥，生成请求仅更换 `modelId`，人物替换参数与配音流程共用。依据[参考项目模型配置](https://github.com/zxc9802/seedance/blob/main/src/modelConfig.js)，2.0 与 fast 的生成档位为 4/5/6/8/10/12/15 秒，2.5 另支持 20/25/30 秒；mini 的完整 ID 及 15 秒上限参照 [Mini 视频编辑接口文档](https://doc.dmxapi.cn/doubao-seedance-2-0-mini-260615-video-editing.html)，沿用 2.0 的时长档位。系统按参考视频时长选择档位。参考视频除 2.5 支持 2–30 秒外，其余限 2–15 秒，文件均限 50 MB；声音参考仍限 2–15 秒、15 MB。模型配置和模拟请求测试不代表已验证当前上游账号的真实生成权限。

上传前及未提交的草稿可切换版本；已上传超过 15 秒的视频时，切换到 2.0、fast 或 mini 会提示更换视频。生成提交后版本锁定，恢复任务与查看记录均保留该版本。`api_cost` 模式下，草稿预估、余额检查、费用预留和结算按上述 2026-10-20 价格表计算，提交时保存单价；未带单价快照的已提交旧任务仍按原 1 元/秒结算。按提交生成时长计算整条任务费用，配音和口型不额外加收；历史固定积分模式保持原规则。

### PixVerse Swap

新增的第五个选项通过 fal.ai 的 `fal-ai/pixverse/swap` 替换人物，不改变默认 qiya-2.0 和已有任务的模型。参考视频限 2–30 秒、长边不超过 1920 像素、50 MB，输出 720p；照片与视频由服务端上传 fal 存储，上传地址和任务回执持久化。请求固定 `mode=person`、`keyframe_id=1`、`original_sound_switch=true`、`enable_safety_checker=true`，不向此接口发送 Seedance 的提示词、素材 ID 或参考声音参数。[fal 接口](https://fal.ai/models/fal-ai/pixverse/swap/api)、[PixVerse 素材限制](https://docs.platform.pixverse.ai/swap-1740834m0)。

PixVerse 本身保留原声，不负责换声。页面继续默认使用声音参考，经 IndexTTS2 配音、VEED 口型处理后合成，并复用原字幕提取与回填流程。2026-10-20 的真实 4 秒样片已验证人物替换接口、720p 输出与原声保留；该样片丢失了原字幕，因此最终字幕需依赖后处理，提取或合成失败时会显示提示。完整配音、口型、字幕链路另有自动化模拟测试，尚不代表各时长的视觉效果验收。

计费使用 `CREDITS_BILLING_MODE=api_cost`：PixVerse、每段 IndexTTS2 和口型调用分别记录 fal 实时单价、汇率、请求编号与实际用量，按现有 125 积分/元折算，不套用 qiya 的整条任务单价。fal 公布的 720p 人物替换费用为 5 秒内 $0.20，超过 5 秒 $0.40，配音和口型另计；实际扣费以供应商回执为准。[fal 价格](https://fal.ai/models/fal-ai/pixverse/swap)。实际查询本次 4 秒样片的单价为 $0.05/计费单位、回执用量为 4，合计 $0.20，计费单位不能直接当作视频秒数。

复用 `FAL_KEY` / `FAL_API_KEY` / `VIDEO_FAL_KEY`，无需额外 PixVerse 密钥。fal 未配置或积分服务未启用 `api_cost` 时禁用这一选项，避免误用旧固定积分价格；原有 qiya 配置和定价不变。缺少费用回执时保留待结算并重新读取已保存回执，不重复生成；提交结果不确定且没有任务编号时保留费用待核对。

### Wan 2.2 人物替换

第六个选项使用 fal.ai 的 `fal-ai/wan/v2.2-14b/animate/replace`，提交到 `https://queue.fal.run/fal-ai/wan/v2.2-14b/animate/replace`。照片与视频由后台上传 fal 存储，分别作为 `image_url` 和 `video_url`；请求指定 `resolution=720p`、`enable_safety_checker=true`，其余采样参数沿用官方默认值。此接口不接收 Seedance 提示词、声音参考或原声开关；生成提示词由上游自动产生。[官方接口](https://fal.ai/models/fal-ai/wan/v2.2-14b/animate/replace/api)

本站上传范围沿用 2–30 秒、50 MB、宽高至少 300 像素；30 秒是工作台限制，官方公开接口未注明最大视频时长。选择声音参考时使用现有 IndexTTS2 配音及 VEED 口型流程，不以此替换接口承担音色克隆。素材地址、生成与口型任务编号持久化，重启查询原任务；提交确认中断不自动重复付费调用，缺少费用回执继续查询原结果。自动化测试覆盖模型选择、上传、恢复、配音口型、字幕和费用结算，尚未验收真实付费生成效果。

复用 `FAL_KEY` / `FAL_API_KEY` / `VIDEO_FAL_KEY`，无需新增模型环境变量。计费要求 `CREDITS_BILLING_MODE=api_cost`，人物替换、配音与口型分别按 fal 实际回执结算。官方公布 720p 按每 16 帧 $0.08 计费，不能直接用视频时长乘 $0.08；例如 5 秒、24 fps 为 120 帧，对应人物替换费用 $0.60。实际记账使用实时单价与 `x-fal-billable-units`，不根据本地时长猜测最终费用。[官方价格](https://fal.ai/models/fal-ai/wan/v2.2-14b/animate/replace)

### 声音参考

可额外上传清晰的单人 MP3 / WAV，2–15 秒、最大 15 MB，指定目标音色。沿用原视频台词、开口时间和停顿，不使用参考音频里的台词。优先提取原视频已有字幕作为文案和成片字幕；无字幕时自动识别人声，不再要求用户确认台词。

页面的「配音模型」可选 Seedance 2.0 或 IndexTTS2，新建复刻默认使用 IndexTTS2，需要上传声音参考；视频人物替换始终使用旗舰模型。配音选择保存到任务，提交后不可切换，成片及历史记录标明使用的配音模型。

Seedance 2.0 直接生成视频与声音：默认保留原视频的声音和情绪参考，上传声音以 `referAudioUrl` 传入，提示词要求跟随参考音色。参考声音可在现有 2–15 秒范围内使用更长、清晰的单人录音，但长度本身不能保证音色准确。该路线不调用 IndexTTS2 或额外的口型服务。

四个 Seedance 生成版本另提供「参考视频声音」选择：默认「原声参考」沿用现有流程；「无原声参考」需上传声音参考，后台先从原片提取字幕、台词和时间线，有音轨时使用 FFmpeg 视频流直拷贝生成 `source-silent.mp4`，素材签名地址只向 Seedance 提供无音轨副本。原片仍保留供用户预览及 IndexTTS2 提取情绪音频。直接由 Seedance 配音时，仍传入上传声音，提示词改为仅以该音频提供音色；采用独立 IndexTTS2 配音时，关闭 Seedance 的音频生成，沿用后续配音和口型流程。模式以 `sourceAudioMode=original|silent` 随任务保存，旧任务默认为 `original`，提交后不可切换；去音轨失败时不提交模型、不回退到带原声素材。PixVerse 和 Wan 不提供此开关，切换到这两者时恢复原声参考。真实音色与口型效果仍需成片试听。

选择 IndexTTS2 时必须上传声音参考：新任务通过 fal.ai 的 `fal-ai/index-tts-2/text-to-speech` 合成，提交地址为 `https://queue.fal.run/fal-ai/index-tts-2/text-to-speech`（[官方接口文档](https://fal.ai/models/fal-ai/index-tts-2/text-to-speech/api)）。上传声音仅作为 `audio_url` 音色参考；按原说话区间截取原视频音频，分别作为 `emotional_audio_url`，情绪强度 `strength=0.8`，关闭从台词推断情绪。台词写入 `prompt`。最多同时合成三段，与 Seedance 人物替换并行处理。各段去掉首尾多余静音，再按原区间调整语速，保留区间之间的静音。IndexTTS2 提供独立音色和情绪参考，但听感、情绪还原程度仍需真实成片试听。

IndexTTS2 两路完成后，以同一条完整配音音轨和 Seedance 视频提交 VEED 视频口型同步；口型处理依赖两路结果，因此这一阶段不能提前并行。最终合成明确映射 IndexTTS2 音轨，不采用 Seedance 或口型服务附带的人声。两种配音路线都保留清晰字幕，不擦除、打码或模糊字幕区域。

已有历史任务继续按提交时的流程处理，未记录配音选择的旗舰模型任务沿用 Seedance 路线。新配音记录标记 `provider=fal`，保存每段的请求编号、状态和结果查询地址；已准备的历史配音记录未带该标记时仍使用 302.AI，不把旧任务编号发送到 fal，也不重新生成已付费片段。IndexTTS2 任务不在配音或口型处理失败时偷偷回退到原声；查询或配音下载暂时失败则继续查询和下载原任务。历史 302.AI 任务明确返回参考音频下载超时或 SSL 连接中断时，最多重试五次并保留已失败的任务编号；fal 明确失败时直接报告失败。配音分段任务和口型任务编号持久化，重启不重复提交付费任务；提交回包不确定时明确提示核对供应商记录。

新配音与口型、文件上传共用 `FAL_KEY` / `FAL_API_KEY` / `VIDEO_FAL_KEY`（按此顺序取第一个非空值），认证为 `Authorization: Key ...`。本地可在根目录 `.env.local` 配置，生产仅读取部署环境。`INDEXTTS_302_API_KEY` / `INDEXTTS_API_KEY` 与 `INDEXTTS_BASE_URL` / `INDEXTTS_API_BASE_URL` 仅用于历史 302.AI 配音恢复及原有语音识别配置回退，不再决定新复刻配音的上游；独立数字人模块不受此变更影响。口型模型复用 `FAL_VEED_MODEL`，默认 `veed/lipsync`。只有选择 IndexTTS2 的新任务在预留积分前检查两项服务配置；缺少这些配置不影响 Seedance 配音。Seedance 读取原素材使用 HMAC 签名；IndexTTS2 的参考声音和分段情绪音频，以及口型服务的生成视频和完整配音，由服务器上传至 fal 文件存储，持久化复用文件地址，设置 3 天过期，避免供应商直接访问网站时出现 SSL 下载失败。用户读取结果仍要求账号归属。到期清理包括分段音频和口型中间文件。

## 连接与部署

实现参照 `zxc9802/seedance` 的 `origin/main`，参考提交 `79f771740241904b7df7f1d40080d056d30d1c01`：

- 素材登记：`POST /openApi/material/create`，`type=1`，照片 `fileType=1`，视频 `fileType=3`，`thirdChannel=1`。
- 素材审核：`POST /openApi/material/pageList`，通过后使用 `asset://<materialId>`。
- 生成：`POST /openApi/generate`，标准版 `doubao-seedance-2-0-260128` / 至臻版 `doubao-seedance-2-5-260628` 共用 `fusion_video` 模式；照片写入 `resources`，视频写入 `referVideoUrl`。人物复刻属于视频编辑，两版均传 `scale=adaptive`、`duration=-1`，比例和时长跟随原视频，避免固定比例和时长被上游拒绝。任务仍保留原有比例与时长档位用于页面展示、预估和结算，不把 `-1` 写入任务时长。
- 声音参考以 `fileType=2` 登记，审核通过后写入 `referAudioUrl`。
- 查询：`POST /openApi/queryResult`，携带 `taskId` 和 `abilityType=VIDEO`。
- 以上接口认证均使用 `projectCode`、`X-Access-Key`、`X-Secret-Key` 请求头。

配置 `.env.example` 中的 `VIDEO_*` 与 `TEMP_ASSET_SIGNING_SECRET`。如素材服务使用相同项目，`MATERIAL_*` 可留空。开发环境读取 `.env.local`；生产仅从部署环境读取，密钥不进入浏览器或 Git。

`VIDEO_PUBLIC_BASE_URL` 必须是本项目服务可被供应商访问的 HTTPS 域名，生产默认使用启动器传入的 `AUTH_PUBLIC_URL`。例如本项目域名为 `https://nrcz.qycm.top`。不要填参考项目的 `PUBLIC_BASE_URL`，否则供应商无法下载本项目的上传文件。

供应商按请求的服务器出口 IP 校验白名单。与 Seedance 使用同一出口 IP、同一组项目凭据时，可沿用现有授权，不需要再放行开发电脑的 IP。开发电脑被拒绝不能说明部署服务器不可用；应从实际部署服务器验证素材服务权限。未授权时页面会明确提示，终止素材审核并退回积分，不会调用视频生成。

沿用现有 `/app/.data` 持久卷，数据位于 `.data/video/`。Docker 已包含 ffprobe；本地需安装 ffmpeg。采用现有单实例文件锁，不支持多个容器共享目录同时写入。反向代理需允许至少 50 MB 的请求体和视频的 Range 请求。

### 结果下载

模型完成后，由服务端下载和检查成片，页面显示已保存字节数；供应商提供总长度时，同时显示总长度。单次下载总超时为 10 分钟，连接超时 15 秒，无数据进展超时 30 秒，累计文件上限 200 MB。任务之间独立处理，一条下载缓慢的任务不会占住其他任务的查询队列。

下载中断会保留临时文件。只有相同结果 URL、强 ETag 及匹配的长度信息才能发送 `Range` / `If-Range` 接续下载，并严格校验 `206` 的起点、总长和 ETag。服务器返回 `200` 或不具备可靠实体标识时从头下载，避免拼接不同版本。已知总长度时，每 10 秒检查当前吞吐量；预计无法在本次剩余总时限内完成就提前中断。有未尝试的公开节点时，持续低于 128 KiB/s 且预计还需超过 30 秒，也会提前中断，保留慢节点记录并在重试时优先换节点。所有节点都尝试过后保留原总超时，避免整体带宽低时不断重下。未知长度和最后 64 KiB 沿用原超时规则。结果地址及每一次重定向均校验公开网络地址，DNS 连接固定到验证过的 IP。下载重试查询或保存同一模型任务，不额外调用生成接口。

供应商返回无查询参数的 `aggregationpic.buerdt.net` 链接时，优先通过其 DNS CNAME 指向的原生 TOS 桶域名下载相同路径。只接受 `*.tos-*.volces.com`，连接仍校验公开地址并固定 DNS；CNAME 查询、原生地址连接或 HTTP 状态不可用时回退原链接。带签名或其他查询参数的链接保持原样。断点元数据仍记录供应商原链接，跨域续传继续严格核对 ETag 与长度。

## 积分、恢复与保存

- 使用项目现有账号积分账本，按视频时长预留积分；成片通过 ffprobe 校验并保存后按实际时长结算，不超过本次预留金额。
- 素材审核失败、模型明确失败或任务超时退回预留积分；结算/退款服务故障会重试，结算完成前不开放结果下载。
- 持久化任务 ID，在同一任务上重复提交不会重复调用视频生成。已取得模型任务 ID 后，服务重启继续查询原任务。
- 失败后重新检查先完成原任务的退款，再使用独立账本 ID `video-recheck:<taskId>:<attempt>` 预留积分；保留原任务的退款记录，不修改已退款账目。复核通过只结算本次预留一次，复核失败退回本次预留。重复点击正在复核或已完成的任务不会新建预留；预留结果回包丢失或进程中断时，按持久化账本 ID 查账和退款，不再次付费生视频。
- 付费提交回包丢失或重启时尚未保存模型 ID：标记未确认并退回本项目预留积分，不自动再次付费提交。上游可能已执行，需核对供应商记录后再创建任务。
- 上传的原文件通过 24 小时 HMAC 签名链接供 Seedance 读取；IndexTTS2 和口型服务读取设置 3 天过期的 fal 文件地址。任务、结果与下载要求登录且归属当前账号。未提交素材 1 天后清理；已提交素材随任务保留 3 天，成功成片从完成时计 3 天。到期清理覆盖原素材、生成原片、成片、断点下载元数据、临时音频、VAD/ASR 中间文件和语音检查诊断，不只删除最终成片。任务编号和计费记录保留用于去重。

真实模型验收还需可访问的 HTTPS 素材域名、供应商 IP 授权和可用额度。模拟接口测试只能验证页面与任务流程，不能代替真实成片的相似度、情绪和口型评估。
