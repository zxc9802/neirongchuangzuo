# AI 视频 · 人物 1:1 复刻

输入一段单个人物的视频，再输入一张目标人物照片，由视频模型替换人物。页面展示为「Max 模型」，供应商模型名仅保留在服务端配置和技术文档中。固定提示词要求保留动作、镜头顺序、场景和说话内容，保留原有清晰字幕及字幕区域的画面细节，保留真实商品包装与场景标识；不新增动作、重复片段或延伸表演。输出时长超过原视频时，要求多出的部分保持末帧静止、闭嘴和无声。这些是生成目标，不是逐帧一致保证。

## 使用

1. 打开「AI 视频 → 人物 1:1 复刻」，选择参考视频和目标人物照片，可额外添加声音参考。账号的页面模式会记住，刷新后继续显示人物复刻。
2. 点击「上传素材，查看费用」。服务端检查视频时长与照片格式，显示生成时长和积分预估。
3. 点击「开始人物复刻」。素材审核、生成、保存与结算状态会自动更新；可离开页面，再从最近记录查看。
4. 成片可播放和下载，也会出现在「资产 → 视频」。成片保留 3 天。

### 声音参考

可额外上传清晰的单人 MP3 / WAV，2–15 秒、最大 15 MB，指定目标音色。沿用原视频台词、开口时间和停顿，不使用参考音频里的台词。优先提取原视频已有字幕作为文案和成片字幕；无字幕时自动识别人声，不再要求用户确认台词。

页面的「配音模型」可选 Seedance 2.0 或 IndexTTS2，新建复刻默认使用 Seedance 2.0；视频人物替换始终使用旗舰模型。配音选择保存到任务，提交后不可切换，成片及历史记录标明使用的配音模型。

Seedance 2.0 直接生成视频与声音：保留原视频的声音和情绪参考，上传声音以 `referAudioUrl` 传入，提示词要求跟随参考音色。参考声音可在现有 2–15 秒范围内使用更长、清晰的单人录音，但长度本身不能保证音色准确。该路线不调用 IndexTTS2 或额外的口型服务。

选择 IndexTTS2 时必须上传声音参考：上传声音仅作为 `speaker_audio_url` 音色参考；按原说话区间截取原视频音频，分别作为 `emotion_audio_url`，情绪强度为 0.8。最多同时合成三段，与 Seedance 人物替换并行处理。各段去掉首尾多余静音，再按原区间调整语速，保留区间之间的静音。IndexTTS2 提供独立音色和情绪参考，但听感、情绪还原程度仍需真实成片试听。

IndexTTS2 两路完成后，以同一条完整配音音轨和 Seedance 视频提交 VEED 视频口型同步；口型处理依赖两路结果，因此这一阶段不能提前并行。最终合成明确映射 IndexTTS2 音轨，不采用 Seedance 或口型服务附带的人声。两种配音路线都保留清晰字幕，不擦除、打码或模糊字幕区域。

已有历史任务继续按提交时的流程处理，未记录配音选择的旗舰模型任务沿用 Seedance 路线。IndexTTS2 任务不在配音或口型处理失败时偷偷回退到原声；明确失败会退款，查询或配音下载暂时失败则继续查询和下载原任务；供应商明确返回参考音频下载超时时，最多重试五次并保留已失败的任务编号。配音分段任务和口型任务编号持久化，重启不重复提交付费任务；提交回包不确定时明确提示核对供应商记录。

配置复用现有 `INDEXTTS_302_API_KEY` / `INDEXTTS_API_KEY`、`INDEXTTS_BASE_URL` / `INDEXTTS_API_BASE_URL` 和 `FAL_KEY` / `FAL_API_KEY` / `VIDEO_FAL_KEY`。口型模型复用 `FAL_VEED_MODEL`，默认 `veed/lipsync`。只有选择 IndexTTS2 的新任务在预留积分前检查两项服务配置；缺少这些配置不影响 Seedance 配音。供应商读取原素材、分段情绪音频、生成视频和完整配音都要求 HMAC 签名；用户读取结果仍要求账号归属。到期清理包括分段音频和口型中间文件。

## 连接与部署

实现参照 `zxc9802/seedance` 的 `origin/main`，参考提交 `79f771740241904b7df7f1d40080d056d30d1c01`：

- 素材登记：`POST /openApi/material/create`，`type=1`，照片 `fileType=1`，视频 `fileType=3`，`thirdChannel=1`。
- 素材审核：`POST /openApi/material/pageList`，通过后使用 `asset://<materialId>`。
- 生成：`POST /openApi/generate`，模型 `doubao-seedance-2-0-260128`，`fusion_video` 模式；照片写入 `resources`，视频写入 `referVideoUrl`。
- 声音参考以 `fileType=2` 登记，审核通过后写入 `referAudioUrl`。
- 查询：`POST /openApi/queryResult`，携带 `taskId` 和 `abilityType=VIDEO`。
- 以上接口认证均使用 `projectCode`、`X-Access-Key`、`X-Secret-Key` 请求头。

配置 `.env.example` 中的 `VIDEO_*` 与 `TEMP_ASSET_SIGNING_SECRET`。如素材服务使用相同项目，`MATERIAL_*` 可留空。开发环境读取 `.env.local`；生产仅从部署环境读取，密钥不进入浏览器或 Git。

`VIDEO_PUBLIC_BASE_URL` 必须是本项目服务可被供应商访问的 HTTPS 域名，生产默认使用启动器传入的 `AUTH_PUBLIC_URL`。例如本项目域名为 `https://nrcz.qycm.top`。不要填参考项目的 `PUBLIC_BASE_URL`，否则供应商无法下载本项目的上传文件。

供应商按请求的服务器出口 IP 校验白名单。与 Seedance 使用同一出口 IP、同一组项目凭据时，可沿用现有授权，不需要再放行开发电脑的 IP。开发电脑被拒绝不能说明部署服务器不可用；应从实际部署服务器验证素材服务权限。未授权时页面会明确提示，终止素材审核并退回积分，不会调用视频生成。

沿用现有 `/app/.data` 持久卷，数据位于 `.data/video/`。Docker 已包含 ffprobe；本地需安装 ffmpeg。采用现有单实例文件锁，不支持多个容器共享目录同时写入。反向代理需允许至少 50 MB 的请求体和视频的 Range 请求。

### 结果下载

模型完成后，由服务端下载和检查成片，页面显示已保存字节数；供应商提供总长度时，同时显示总长度。单次下载总超时为 10 分钟，连接超时 15 秒，无数据进展超时 30 秒，累计文件上限 200 MB。任务之间独立处理，一条下载缓慢的任务不会占住其他任务的查询队列。

下载中断会保留临时文件。只有相同结果 URL、强 ETag 及匹配的长度信息才能发送 `Range` / `If-Range` 接续下载，并严格校验 `206` 的起点、总长和 ETag。服务器返回 `200` 或不具备可靠实体标识时从头下载，避免拼接不同版本。已知总长度时，每 10 秒检查当前吞吐量；预计无法在本次剩余总时限内完成就提前中断。有未尝试的公开节点时，持续低于 128 KiB/s 且预计还需超过 30 秒，也会提前中断，保留慢节点记录并在重试时优先换节点。所有节点都尝试过后保留原总超时，避免整体带宽低时不断重下。未知长度和最后 64 KiB 沿用原超时规则。结果地址及每一次重定向均校验公开网络地址，DNS 连接固定到验证过的 IP。下载重试查询或保存同一模型任务，不额外调用生成接口。

供应商返回无查询参数的 `aggregationpic.buerdt.net` 链接时，优先通过其 DNS CNAME 指向的原生 TOS 桶域名下载相同路径。只接受 `*.tos-*.volces.com`，连接仍校验公开地址并固定 DNS；CNAME 查询、原生地址连接或 HTTP 状态不可用时回退原链接。带签名或其他查询参数的链接保持原样。断点元数据仍记录供应商原链接，跨域续传继续严格核对 ETag 与长度。

## 积分、恢复与保存

- 使用项目现有账号积分账本，按视频时长预留积分；成片通过 ffprobe 校验并保存后按实际时长结算，不超过本次预留金额。
- 素材审核失败、模型明确失败或任务超时退回预留积分；结算/退款服务故障会重试，结算完成前不开放结果下载。
- 持久化任务 ID，在同一任务上重复提交不会重复调用视频生成。已取得模型任务 ID 后，服务重启继续查询原任务。
- 失败后重新检查先完成原任务的退款，再使用独立账本 ID `video-recheck:<taskId>:<attempt>` 预留积分；保留原任务的退款记录，不修改已退款账目。复核通过只结算本次预留一次，复核失败退回本次预留。重复点击正在复核或已完成的任务不会新建预留；预留结果回包丢失或进程中断时，按持久化账本 ID 查账和退款，不再次付费生视频。
- 付费提交回包丢失或重启时尚未保存模型 ID：标记未确认并退回本项目预留积分，不自动再次付费提交。上游可能已执行，需核对供应商记录后再创建任务。
- 上传的原文件只通过 24 小时 HMAC 签名链接供供应商读取；任务、结果与下载要求登录且归属当前账号。未提交素材 1 天后清理；已提交素材随任务保留 3 天，成功成片从完成时计 3 天。到期清理覆盖原素材、生成原片、成片、断点下载元数据、临时音频、VAD/ASR 中间文件和语音检查诊断，不只删除最终成片。任务编号和计费记录保留用于去重。

## 验证

人物替换提示词采用“严格编辑视频1”的任务表述，并明确图片1/视频1/音频1的各自用途。依据[官方提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh&redirect=1)，编辑任务不使用“参考视频”指令，避免被理解为全模态参考生成。该写法仍需真实成片验证，不能视为逐帧一致保证。

`npm run test:video` 检查连接协议、签名、账号隔离、校验、台词确认、静音区间提示词、积分预留/退款/结算、复核账本、重复提交、重启恢复及到期清理，也包括真实 HTTP 断点下载测试。`npm run check`、`npm test` 和 `npm run build` 用于项目回归及构建。真实 Silero/FFmpeg 测试要求本地可用 Python、numpy、onnxruntime、ffmpeg 和 ffprobe；仅跳过该测试不能说明语音对齐已验证。macOS 若临时目录是符号链接，可用 `TMPDIR=/private/tmp npm test`；账本按现有规则拒绝符号链接目录。

真实模型验收还需可访问的 HTTPS 素材域名、供应商 IP 授权和可用额度。模拟接口测试只能验证页面与任务流程，不能代替真实成片的相似度、情绪和口型评估。

2026-10-08 已配置并部署到 `https://nrcz.qycm.top/#video`，使用与 Seedance 相同的服务器出口及供应商项目凭据，服务器素材查询成功，无需额外授权开发电脑 IP。Computer use 使用独立验收账号，经仅绑定本机回环地址的代理隔离登录 Cookie，所有页面、上传、任务和结果请求均转发到生产服务，没有模拟生成响应。

2026-10-08 的不带声音参考样例使用虚构女性的 5.088 秒口播视频和另一位虚构男性的照片，实际生成 720×1280、约 6.06 秒含音频的视频。抽查不同时刻的画面，确认人物已替换为目标男性，灰发、眼镜、蓝色上衣、微笑和挥手可见；原场景保留，抽查未见字幕。原视频与结果的语音转写一致。页面播放、下载、刷新恢复及资产库收录通过；生产账本仅有一次 67 积分预留和一次结算，余额从 1000 变为 933、冻结归零。此记录仅验证该历史样例，不能作为声音参考版本或所有输入的 1:1 效果验收。
