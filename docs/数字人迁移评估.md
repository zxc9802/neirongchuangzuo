# 数字人迁移评估

评估日期：2026-09-23。源仓库：[zxc9802/shuzirenzhinengti](https://github.com/zxc9802/shuzirenzhinengti)，检查版本 `393d2eccd7d6e1b1d7423f40e1d7e97cef73b2cd`。

后续实施更新：用户已选择直接采用该项目的后端，前端由本项目统一开发，沿用现有浅色三栏风格。源码已导入 `services/digital-human/`，5173 的 `/#avatar` 页面通过同源代理接入 3001 服务；原生制作台保留用于联调。新页面提供视频形象库、音色管理、文案及真实参数、进度、历史、下载与可恢复任务操作。本轮验收结果见[数字人接入验收](数字人接入验收.md)。开发方式见仓库 README，接口见 [数字人前端对接](数字人前端对接.md)。以下保留初次评估结论，并注明实施状态。

## 结论

可以迁移，建议复用其数字人生成后端，保留本项目的页面和门店宣传定位。源项目已有真实生成流程和服务接口，但仍依赖外部付费模型；本次未调用这些模型验证成片质量。

最适合先落地的流程是：上传老板口播视频 → 选择或上传参考声音 → 填写宣传文案 → 生成配音和对口型视频 → 查看进度、预览、下载 MP4。

关键差异：源项目的数字人形象来自人物视频，图片只是视频封面。因此新版页面采用视频形象输入，替换原型中的照片口播设计。单张照片生成口播不属于本次接入范围。

## 推荐接入方式

本项目目前是原生 JavaScript 静态原型；源项目是 Next.js、React、TypeScript 全栈应用。不能只复制一个页面就获得生成能力。

本轮采用独立数字人服务及同源代理：`design/digital-human.js`、`design/digital-human.css` 实现本站页面，`design/digital-human-api.js` 适配接口，`preview.mjs` 将 `/api` 及 `/jobs` 等请求流式转发到 3001，保留会话、媒体 Range 和事件流。这样复用生成链路及任务状态，无需先重写全部引擎。

`npm run dev` 使用 `scripts/dev.mjs` 同时启动工作台与后端，或复用已经运行的数字人服务；`npm run dev:design` 只启动工作台与代理。新状态接口 `/api/digital-human/status` 返回配置就绪布尔值，不返回密钥，也不代表供应商已实测可用。缺少生成接口凭据或公共媒体条件时，页面禁用生成；素材上传仍可真实持久化。

重点接口：`/api/avatars`、`/api/voices`、`/api/tasks`、`/api/tasks/[id]`、`/api/tasks/[id]/stream`、`/api/tasks/[id]/download/[file]`。具体上传及文件授权逻辑应沿用服务端已有实现。

## 运行条件和需要调整的地方

- Node.js 常驻服务、FFmpeg/ffprobe、持久化媒体目录。本机已具备 FFmpeg/ffprobe。
- 配音接口凭据 `INDEXTTS_302_API_KEY`，以及至少一种对口型服务的凭据。接口适配存在不代表账号已经开通或额度可用。
- 外部模型必须能读取输入媒体，需要可公网访问的服务地址或对象存储；仅使用 `localhost` 不够。
- 采用已有独立账号模式时，需要 `AUTH_MODE=standalone` 和 PostgreSQL 连接 `AUTH_DATABASE_URL`。独立账号不走原主站积分扣费，但模型调用仍产生费用。
- 本地代理来源配置为 `AUTH_PUBLIC_URL=http://127.0.0.1:5173`、`AUTH_DESKTOP_URL=http://127.0.0.1:3001`。仅本机且未配置 SSO 的开发模式可免登录，生产环境保留鉴权限制。
- 接口配置实际从服务器环境变量读取；代码中的配置保存函数不支持通过页面保存密钥。部署时以代码行为为准。
- 替换源代码里的原项目存储桶和地域默认值，使用本项目的存储配置。
- 当前任务依靠进程内后台执行及文件/对象存储记录，适合先做单实例联调。正式多人使用前，需要评估持久任务队列、重启恢复和并发控制；现有恢复逻辑并不覆盖所有执行阶段。

## 实施与后续验收

1. 本轮实现统一风格的数字人页面、接口适配、同源代理和一键启动，验证素材上传与刷新后的持久化。
2. 配置自己的账号、存储和模型接口，用一段短视频验证真实提交、任务进度、成片预览与下载；状态显示就绪不能替代这一步。
3. 验收历史记录及服务端允许的任务恢复，再统一全站账号和素材管理。恢复已有任务不同于重新创建可能收费的生成任务。
4. 依据实际产品需要增加字幕、门店信息、背景或包装效果。这些尚未接入，新页面不提供对应的假设置。
