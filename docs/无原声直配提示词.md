# 无原声直配（试用）：完整提示词

此示例直接由 `services/video/provider.mjs` 的 `generationBody()` 生成，展示全部提示词，未省略人物替换、字幕或声音要求。

示例使用 10 秒视频，两句台词位于 1–4 秒、5–8 秒。`【第1句原片台词】`、`【第2句原片台词】` 是占位符；实际请求会替换为原片识别出的完整台词与时间戳。若原片没有可提取的字幕，将不包含“台词来自原视频字幕”这一段，其余声音约束仍保留。

图片1是用户上传的人物照片，视频1是实际删除全部音轨后的参考视频，音频1是用户上传的声音参考。

```text
编辑视频1。将视频1中的唯一人物完整替换为图片1中的人物。图片1是人物外貌的唯一参考，头部、脸型、五官及其比例、眉眼、鼻子、嘴唇、耳朵、下颌轮廓、发际线和发型都必须采用图片1；不得保留视频1原人物的脸部特征，不得混合两个人的五官，不能只换衣服而保留原脸。人物的服装采用图片1，去掉原人物与图片1不一致的服装、配饰和衣服文字，不新增图片1中不存在的装饰。替换从第一帧开始并保持到最后一帧。沿用视频1的动作、表情变化、说话节奏、位置和镜头运动，不增加动作、不重复片段、不延伸表演。人物以外的场景、商品及包装、背景标识和已有字幕保持原样；保留字幕的原文、位置、排版和出现时间，不重画字幕。
视频1实际时长为10.000秒。动作严格对应原视频时刻，输出超过原视频时长的部分保持末帧静止、闭嘴和无声。
台词来自原视频字幕，优先于听辨结果，以下文字是唯一语音文案，不改写、不漏说，数字和价格按原字说：1.000–4.000秒：【第1句原片台词】；5.000–8.000秒：【第2句原片台词】。保留视频1已有的清晰字幕，不重画字幕，不修改字幕区域的背景；仅在成片未保留字幕时，系统会按原文补字幕。
视频1已去除原声音轨，仅提供画面、动作、表情和说话节奏参考。以下从原片预先提取的台词和时间线是唯一配音依据。音频1是用户上传的声音，也是唯一音色参考；生成视频中人物的音色、声线、共鸣和音质必须跟随音频1，不根据视频1中的人物外貌推测声音，不推测或恢复原人物的声音。情绪表达参考视频1的表情、动作和台词语义，在音频1音色的基础上自然表达。人物口型与新生成的配音同步。音频1仅提供音色，不使用音频1的台词，也不同时播放音频1，不沿用音频1的平淡语气或情绪。全片只有图片1中的一个人物说话，使用音频1的同一音色，不保留或混入原视频的人声，不添加旁白或第二个人声。原视频人声从第 1.000 秒开始，此前人物不得说话。严格按以下原视频时间线说话：1.000–4.000 秒：【第1句原片台词】；5.000–8.000 秒：【第2句原片台词】。每段仅说一次，严格按顺序，价格、数字、单位按原字说，不改写、不补全、不重复。只在列出的台词区间说话，0.000–1.000秒；4.000–5.000秒；8.000秒至成片结束必须保持静音。最后一段结束后不得补说或复读。
```

该模式由 Seedance 同时生成画面与声音，不另行调用 TTS 或口型模型。移除视频音轨可排除原片声音作为输入参考，但不能保证模型每次都准确复制上传音色；还需用真实成片试听验证。
