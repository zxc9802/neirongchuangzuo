# 生成资产与 3 天保留期

更新：2026-09-30。

侧栏「资产」现在打开独立的生成资产页（`/#assets`）。它收录通过本站成功生成的图片、数字人成片与配音，支持类型筛选、预览、下载和分批加载。原图、上传形象、源声音、草稿及参考示例不计入成品资产。

## 保留规则

- 按每份任务**首次生成成功时间**起算 72 小时，按完成时间倒序显示。重看、下载、重启服务、修改日志不延长保留期。
- 卡片显示生成时间、剩余时间和具体到期时间。到期时前端移除卡片，后端拒绝旧预览、下载链接。
- 后台在服务启动、相关请求和每分钟扫描时清理已过期生成文件。服务停机期间无法执行磁盘清理，恢复服务后补做；访问检查仍按固定到期时间执行。
- 清理只处理受管理任务目录中已知的生成文件，拒绝符号链接或路径越界。上传原图、形象、音色及作为其他任务输入的共享原始素材保留。
- 任务编号、图片请求指纹及数字人计费记录继续保留，用于防止重复提交或保留处理记录。它们不会作为过期成品出现在资产页。

## 接入范围

图片使用 `GET /api/ai/images?completed=true`，返回全部未到期成品及 `expiresAt`，不受普通任务历史 100 条上限影响。数字人使用 `GET /api/tasks?completed=true`，沿用原有登录、所有者与管理员权限检查，返回已完成且可交付的成品。前端只接受这些接口返回的本站成品地址。

视频与音频来自当前已接入的数字人服务；AI 视频、AI 混剪仍待接入真实生成后端，其示例不会冒充生成资产。

图片清理覆盖 `.data/ai/<任务编号>/result-*`，过期文件请求返回 `410 RESULT_EXPIRED`。数字人清理覆盖本站任务目录和已配置对象存储中该任务的固定输出文件；原始输入、其他路径与共享缓存不清理。

## 验证

- 根项目语法检查通过，回归测试 90 项通过。
- 图片测试覆盖精确 72 小时边界、启动和无请求定时清理、清理失败重试、旧请求编号不再次调用模型、目录链接隔离；106 个成品不会被 101 个较新失败任务挤出资产页。
- 前端测试覆盖完成时间计算、到期过滤、上传与参考图排除、数字人成片/配音筛选、未结算结果排除和排序。
- 外置 Chrome 实测：5 张既有成品正常展示、类型筛选与空态正常、图片放大与下载成功，无控制台错误。本轮没有提交新的模型生成任务。
- 数字人保留期及权限专项 42 项通过，类型检查通过，源码兼容修复后补验 15 项通过。全量服务测试仍有原仓库的 Windows 路径、SSO/COS 配置及测试沙箱兼容问题；已通过禁用新增保留规则的对照排除本次过期逻辑影响，不能将数字人全量检查视为通过。详见 [数字人测试记录](../services/digital-human/tests/RETENTION.md)。没有创建真实口播任务，也未访问真实对象存储来验证清理。
