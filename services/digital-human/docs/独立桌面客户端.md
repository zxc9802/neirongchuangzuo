# 数字人工作室桌面客户端

Windows / macOS 安装包预设 `https://digital-human-studio-qycm.zeabur.app`。用户安装、注册邮箱账号后即可使用，无需配置数据库、COS、模型 Key 或 SSO。首次打开进入独立登录页，已登录用户直接进入制作台。客户端需要联网。

## 复用现有云端服务

```text
Electron 安装包 → digital-human-studio-qycm.zeabur.app（现有 Zeabur 数字人服务）
                     ├─ PostgreSQL / digital_human_auth：独立账号、会话、登录限流
                     ├─ 腾讯云 COS：现有素材和生成文件，按账号授权访问
                     └─ 现有语音、唇形及动效模型配置
```

在现有 `shuzirenzhinengti` 服务中新增：

```dotenv
AUTH_MODE=hybrid
AUTH_PUBLIC_URL=https://shuziren.qycm.top
AUTH_DESKTOP_URL=https://digital-human-studio-qycm.zeabur.app
AUTH_DATABASE_URL=<现有 zhuzhan PostgreSQL 的私网连接串>
```

`AUTH_DATABASE_URL` 只存在 Zeabur 服务端。当前私网主机使用 `service-69b102f2d00471cc19a119c1:5432`，已在数字人容器内验证连接；控制台通用别名 `postgresql.zeabur.internal` 在此项目返回另一套认证，不能混用。首次注册自动创建 `digital_human_auth.users`、`sessions`、`attempts`，不修改 `public.users` 或主站 SSO 表。多服务导出了同名 `POSTGRES_CONNECTION_STRING` 时，应核对具体数据库，不能盲目引用同名变量。

客户端域名指向同一运行服务，避开当前原域名的 Cloudflare 访问异常。`AUTH_DESKTOP_URL` 同时加入独立账号的同源校验白名单与 COS 上传 CORS 白名单。

保留原来的 `COS_*`、`INDEXTTS_*`、`LIPSYNC_PROVIDER`、`OPENLUX_*` / `FAL_KEY`、`MOTION_*` 等变量，继续由后端调用。安装包不包含数据库密码、COS SecretKey、模型 Key 或后端环境文件。COS 的签名上传链接仍由已认证后端按账号签发。

`hybrid` 模式：`/login`、`/register` 和独立账号接口开放；携带独立会话的请求走独立账号授权；其他请求继续走现有 SSO。无效的独立会话不会降级为匿名权限。`standalone` 模式则完全关闭 SSO；默认 `sso` 模式保持原网站行为。

独立账号为普通用户，只能访问自己的任务、形象和声音；不会继承主站管理员权限或已有账号的私有素材。独立账号不走主站积分扣费，模型与 COS 费用由服务提供者承担，仍受服务端生成限流约束。

## 登录与数据持久化

- 邮箱注册、密码登录、退出、修改密码；密码长度 10–128 位。
- scrypt 加盐密码摘要；数据库仅存储会话令牌的 SHA-256 摘要。
- 30 天 HttpOnly / Secure / SameSite=Lax 会话 Cookie。退出立即撤销会话，修改密码撤销其他会话。
- PostgreSQL 事务处理并发注册、密码修改及会话颁发；持久化认证限流；同源校验阻止登录 CSRF。
- 本版本没有邮件验证与忘记密码邮件功能。

账号和会话由现有 PostgreSQL 备份策略覆盖。任务及素材元数据继续沿用现有服务持久化和 COS 同步机制，因此数字人服务保持单实例；本次没有迁移任务存储，也未把全站数据改为关系数据库。

## 开发与验证

```bash
npm ci
# 指向开发 PostgreSQL，账号 schema 自动创建
AUTH_DATABASE_URL=postgresql://user:password@localhost:5432/studio npm run dev:standalone
npm run desktop:install
npm run desktop:dev
```

开发客户端可通过“工作室 → 连接 / 切换服务”连接 `http://localhost:3000`。发布版只接受 HTTPS。正常用户不需要使用此菜单。

```bash
# 指向允许创建临时数据库的测试 PostgreSQL，测试结束仅删除自己创建的数据库
TEST_DATABASE_URL=postgresql://user:password@localhost:5432/postgres npm test
npm test --prefix desktop
npm run build
npm run desktop:mac
npm run desktop:win
```

未设置 `TEST_DATABASE_URL` 时，账号 PostgreSQL 集成测试会明确跳过；其他回归仍执行。不要把生产数据库连接填入测试变量。

## 交付

安装包输出在 `release/`：Windows x64 `.exe`、macOS Apple Silicon / Intel `.dmg`。GitHub Actions 的 `Build desktop installers` 支持手动生成安装包。

当前构建未配置 Apple Developer 公证和 Windows 代码签名证书，系统可能显示来源验证提示；正式大规模分发需要配置签名。这不影响云端连接配置，但不能把未签名测试包称为无提示安装的正式发行版。
