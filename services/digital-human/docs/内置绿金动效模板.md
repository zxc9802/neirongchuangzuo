# 内置绿金动效模板

## 参考片拆解

参考：用户提供的 `飞书20260915-145709.mp4`，1080 × 410、30 fps、101.767 秒，无音轨。文件元数据包含 `Made with Remotion 4.0.514`。以下是逐帧观察后的实现分析，没有原始工程时不能确认它的具体源码。

- 底板：中心略亮的深绿径向渐变，外层暗金线与内层亮金细线贯穿全片。
- 图形：人物、文件、芯片、书本、齿轮等二维线稿，图标和文字彼此独立。不是一张固定图片在移动。
- 时序：第一节点出现；约 0.8–1 秒后连线向右生长；第二节点出现；第三节点出现后变黄并画出椭圆圈注。长片按讲解段落切换图解，背景保持连续。
- 关系：顺序流程、一分二、多个输入汇总、加法公式及结论卡，靠节点位置与箭头表达关系。
- 可实现方式：SVG `path` / `ellipse` 配合 `pathLength`、`strokeDasharray`、`strokeDashoffset`，文字用按帧控制的透明度与少量位移；由 Remotion 逐帧渲染编码。

固定模板提取的是视觉样式和可复用结构，未把参考片及其中的原文烧录为模板素材。

## 两个固定模板

| 模板 | 固定标识 | 可替换内容 |
| --- | --- | --- |
| 绿金文字总结 | `builtin_green_text`，revision 1 | 黄色标题、两行白色总结、黄色高亮词及下划线 |
| 绿金流程图解 | `builtin_green_diagram`，revision 2 | 按口播生成一至四个节点、图标与关系，支持流程/分支/汇总/对比/公式/并列要点 |

入口：数字人动效 → 页面底部「动效库」→「内置固定模板」。每张卡片有可播放的预览，点击「应用到成片」后，在现有总结编辑区修改文案。新版图解会调用配置的 DeepSeek 理解字幕和校对后的总结，选择节点、图标与关系，再用固定代码绘制；保存修改后的文案时更新图解。相同文案与版本的预览、导出复用缓存，不重复分析。文字模板不需要额外语义分析。

历史图解 revision 1 的代码、预览及手动结构仍可读取：三段文案依次对应节点，图标按关键词选择。已使用旧版的任务在动效库重新点击「应用到成片」，即可升级到语义图解；不会静默改变旧版本的内容。

内置模板是所有账号共用的只读代码目录，不写入个人动效表，也不经过 Pi/DeepSeek 重新生成代码；图解的口播理解由 DeepSeek 完成，结果保存在各自项目内。应用时固定模板 ID 和 revision 随项目保存。个人生成的动效、版本和素材依然只对所属账号可见。上线启用账号隔离时，模板 API 同样要求登录；模板的通用预览视频为公开静态资源。

模板在 1080 × 544 的成片底部总结区内重排，顶部标题同步绿色背景，中间人物裁剪和口播字幕沿用当前项目。它不逐秒复制参考片的 101 秒内容，也不会覆盖每个人的私有动效。

## 维护与重建

- 源码：`src/remotion/templates/GreenText.tsx`、`GreenDiagram.tsx`（旧版）、`GreenSemanticDiagram.tsx`（新版）。
- 注册与公开元数据：`src/lib/motion-library/builtins.ts`。
- 编译产物：`src/lib/motion-library/builtin-compiled.json`，随源码入库，供服务端返回沙箱预览及导出使用。
- `npm run motion:bundle` 会重新校验、编译模板源码，并构建 Remotion 与沙箱预览包。
- `node scripts/render-builtin-previews.mjs builtin_green_diagram-v2` 单独生成新版图解预览和海报；省略参数时重建所有版本。预览文案为固定示例，应用后使用用户自己的口播分析结果。
- 发布后若改变已有模板的表现，应保留旧版本、增加 revision，同时更新带版本的预览路径；不能静默替换已发布 revision 的行为。
